# GitHub for Authors: A Beginner Manual

Host a free author site, track your edits, and publish book excerpts — with GitHub Pages. Step by step, no code assumed.

Written for **Dylan Asdale**, registered nurse turned AI author and founder of **Asdale Dynamics, LLC** (Indiana, formed October 2026), author of *The Massive AI Manual* and publisher of the hub site dylanasdale.github.io.

This guide explains publishing tools "like a friend would": plain English, step by step, never condescending.

## Who this is for

You are an author. Maybe you have written a book, maybe you are working on one, or maybe you just have ideas you want to share online. You do not need to be a programmer. You do not need to know what "the command line" is. You do not need to pay for hosting.

If that sounds like you, you are in the right place.

## What this manual covers

1. Welcome — who this is for and what you will learn
2. Create your GitHub account
3. Create your author repository
4. Track your edits (commits, history, and reverting)
5. Publish your free author site with GitHub Pages
6. Publish excerpts from your book
7. Printable checklist

## How to use this manual

- **Read the Markdown version:** open the files in `docs/` in any text editor or Markdown viewer.
- **Browse the HTML site:** open `site/index.html` in your web browser. No server or installation is required.
- **Print the checklist:** open `site/printable-checklist.html` and use your browser's Print command (Ctrl+P / Cmd+P). A print stylesheet is included so the checklist prints cleanly.
- **Markdown source:** lives in `docs/` and can be opened in any text editor or Markdown viewer.
