# 1. Welcome

## Who this is for

You are an author. Maybe you have written a book, maybe you are working on one, or maybe you just have ideas you want to share online. You do not need to be a programmer. You do not need to know what "the command line" is. You do not need to pay for hosting.

This manual was written for Dylan Asdale — a registered nurse turned AI author and founder of **Asdale Dynamics, LLC** (Indiana, formed October 2026). Dylan writes *The Massive AI Manual* and runs the hub site dylanasdale.github.io. He explains things "like a friend would": plain English, step by step, never condescending.

If that sounds like you, you are in the right place.

## What you will learn

By the end of this manual you will be able to:

- Create a free GitHub account
- Create a repository (a project folder in the cloud) for your author site
- Track your edits so you can see what changed and go back to an earlier version
- Publish a free author website with GitHub Pages
- Publish excerpts from your book as pages on that site
- Follow a printable checklist so you never miss a step

## What you need

- A computer with a web browser (Chrome, Firefox, Safari, or Edge)
- An email address
- About an hour, broken into short sessions if you prefer

## How this manual is written

Every step tells you exactly what to click, type, or look for. Words you might not know are explained the first time they appear. Nothing is assumed.

If you get stuck, reread the step slowly. GitHub changes its buttons and wording from time to time, so if a button has a slightly different name than what you see here, look for the closest match — it almost certainly exists.
