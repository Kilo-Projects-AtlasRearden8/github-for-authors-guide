# 3. Create your author repository

A **repository** (or "repo") is a project folder stored on GitHub. It will hold your author site files, your book excerpts, and the history of every edit you make.

## Step 1: Sign in

1. Go to `github.com` and sign in with your username and password.

## Step 2: Create a new repository

1. In the top right, click your profile picture, then click **Your repositories**.
2. Click the green **New** button (or **+** then **New repository**).
3. Under **Repository name**, type a name for your site. A good choice is your username again, for example `dylanasdale`. This makes your site address match your username exactly.
4. Leave **Description** blank, or type something like "My author site and book excerpts."
5. Choose **Public**. GitHub Pages is free for public repositories.
6. **Important:** Check the box **Add a README file**. This gives your repository a starting page.
7. Click **Create repository**.

## Step 3: Look around your new repository

You will see a list of files. For now there is just one: `README.md`. That file is the front page of your repository and, soon, the front page of your author site.

## What you just did

You created a public repository on GitHub. It is empty except for a README file, and it is ready to become your author site.
