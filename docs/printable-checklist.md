# Printable checklist

Print this page and check off each step as you complete it.

---

## GitHub for Authors — Setup Checklist

### Phase 1: Account
- [ ] I created a GitHub account at github.com
- [ ] I verified my email address
- [ ] I chose a username I am happy with (this becomes part of my site address)

### Phase 2: Repository
- [ ] I created a new public repository
- [ ] I added a README file when creating it
- [ ] I can see my repository on GitHub

### Phase 3: Track your edits
- [ ] I edited a file directly on GitHub (used the pencil icon)
- [ ] I wrote a clear commit message
- [ ] I opened the Commits page and saw my change listed
- [ ] I know how to view an older version of a file

### Phase 4: Publish your author site
- [ ] I went to Settings → Pages in my repository
- [ ] I selected the main branch as the source
- [ ] I clicked Save
- [ ] I waited for the green "Your site is published" message
- [ ] I visited my site at `https://username.github.io/`
- [ ] My site shows the README content

### Phase 5: Publish excerpts
- [ ] I created a new file for an excerpt (for example `excerpt-chapter-1.md`)
- [ ] I wrote the excerpt and committed it
- [ ] I visited the excerpt page on my site
- [ ] I added an excerpts section to my README
- [ ] I linked to where readers can buy the full book

---

## Maintenance reminders
- [ ] I commit after every meaningful edit
- [ ] I write commit messages I will understand in six months
- [ ] I check my published site after making changes
