4. Track your edits

One of GitHub's best features for authors is that it remembers every change. You can see what you changed, when you changed it, and go back to an earlier version if you ever want to.

Key terms

Commit
A saved snapshot of your files, with a short message describing what changed.
Commit history
The list of all your commits, newest first.
Revert
Go back to an earlier version of a file.

How to make an edit (save a change)

GitHub lets you edit files directly in your browser.

  1. Open your repository on GitHub.
  2. Click the file you want to edit (for example README.md).
  3. Click the pencil icon (Edit this file) in the upper right of the file view.
  4. Make your changes in the text box.
  5. Scroll to the bottom. Under Commit changes, type a short message, for example:
  • "Updated my author bio"
  • "Added excerpt from Chapter 1"
  • "Fixed a typo on the about page"
  1. Choose Commit directly to the main branch.
  2. Click Commit changes.

See your edit history

  1. In your repository, click the Commits link near the top of the file list.
  2. You will see every commit, who made it, when, and the message you wrote.
  3. Click any commit to see exactly what changed in that version.

Go back to an earlier version

  1. Open the file you want to restore.
  2. Click the History or Commits button for that file.
  3. Click the commit you want to return to.
  4. Click Browse files at that commit, then open the file.
  5. Click the pencil icon, make no changes, and click Commit changes with a message like "Restored earlier version of README.md".

This creates a new commit that brings back the older content. Nothing is ever truly deleted.

Tip for authors: write your commit messages like diary entries — short and clear. Six months from now, "Added Chapter 3 excerpt" will tell you exactly what happened. "Fix" will not.
